## 📚 Context

### ffmpeg Commands Reference

**Probe duration:**
```bash
ffprobe -v quiet -show_entries format=duration -of csv=p=0 "input.mp4"
```

**Extract audio (mp3 128kbps mono):**
```bash
ffmpeg -i "input.mp4" -vn -ac 1 -ab 128k -f mp3 "output.mp3"
```

**Split into 10-min chunks with 1-sec overlap:**
```bash
# Chunk 0: 0s → 601s
ffmpeg -i "input.mp3" -ss 0 -t 601 -c copy "chunk_000.mp3"
# Chunk 1: 600s → 1201s  (starts 1s before last chunk ended)
ffmpeg -i "input.mp3" -ss 600 -t 601 -c copy "chunk_001.mp3"
# etc.
```
