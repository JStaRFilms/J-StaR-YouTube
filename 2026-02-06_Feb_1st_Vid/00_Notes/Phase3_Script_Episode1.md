## IMPORTANT NOTE: Script vs Outline

Since you're filming this LIVE (building the actual site) and cutting into series episodes, this script is structured as:

1. **SCRIPTED sections** — The hook, transitions, and outro (you should know these)
2. **OUTLINE sections** — The build segments where you talk naturally while screen recording
3. **TALKING POINTS** — Key things to mention during live coding sections

You'll be authentic on camera, not reading a teleprompter. The script guides your flow.
